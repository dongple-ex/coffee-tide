# 데스크톱 바리스타와 웹 미니카드

기준: 2026-09-23 · 로컬 소스 `ea4bcb5` · 웹 앱 1.2.2 / Electron 패키지 0.1.0

## 1. 두 방식의 구분

| 항목 | 웹 미니카드 | 데스크톱 바리스타 |
|---|---|---|
| 구현 | `DesktopBaristaPip.tsx`, Document Picture-in-Picture | `desktop/`, Electron 44.3.0 |
| 설치 | 지원 브라우저에서 웹만으로 사용 | Windows 보조 앱 실행 필요 |
| 화면 | 작은 채팅·캐릭터·입력창, 기존 테마 복사 | 투명·테두리 없는 캐릭터 창, 트레이 |
| 크기 | 초기 요청 170×200, 실제 크기는 브라우저 제한에 따름 | 별도 Electron 창·위치 설정 |
| 브라우저 상단 바 | 제거하지 못함 | 웹 브라우저 창과 별개 |
| 왼쪽 Shift 두 번 | 해당 웹/PiP 창에 포커스가 있을 때 | Windows 전역 키보드 훅이 준비된 동안 |
| 본체 창 최소화 | 최신 보조 앱과 연결되고 `windowControl` 지원 시 요청 | marker로 확인한 Chrome/Edge 창만 제어 |

모바일 바리스타 독은 페이지 안의 별도 UI다. 웹 미니카드나 Windows 창 제어와 동일 기능으로 설명하지 않는다.

## 2. 미니카드 동작

1. 지원 브라우저에서 미니카드를 열면 Document PiP를 요청한다.
2. 작은 대화창에서 질문·답변을 표시한다. `page.tsx`의 공통 대화 처리 함수를 사용하되 별도 대화 이력을 전달한다.
3. `_` 버튼은 내용을 접고 높이를 브라우저 프레임 + 28px로 줄이기를 시도한다. 크기 변경이 제한되어도 내용 접기는 유지한다. 실제 OS 최소화나 창 종료가 아니다.
4. 연결된 보조 앱이 창 제어를 지원하면 약 250ms 뒤 본체 최소화를 요청한다. 미연결 상태에서는 요청하지 않는다.
5. 관리 중인 본체를 왼쪽 Shift 두 번으로 복원하면 복원 이벤트가 전달되고 웹 미니카드를 닫는다. PiP 자체를 닫을 때도 본체 복원을 시도한다.

입력 중인 질문·대화 보존 및 포커스 전환은 브라우저/실제 창 환경에서 별도로 검증한다. 브라우저의 크기·포커스·사용자 제스처 정책을 우회한다고 보장하지 않는다.

## 3. 연결과 단축키

- 설정의 데스크톱 바리스타 연결에서 보조 앱에 표시되는 6자리 코드로 페어링한다.
- 연결 토큰은 메모리에 보관한다. 새로고침·연결 만료 시 재연결이 필요하다.
- 왼쪽 Shift만 두 번 눌렀다 뗀다. 각 누름은 250ms 이내, 두 keyup 간격은 70~500ms다. 오른쪽 Shift·길게 누름·다른 키 조합은 제외한다.
- 웹 감지: `src/lib/ui/shortcuts.ts`. Windows 전역 감지: `desktop/hotkey.cjs`, `desktop/native/left-shift.cs`.
- 연결된 탭이 있으면 재사용한다. 미연결 상태에서만 `COFFEETIDE_URL`의 `/#copilot`을 연다.
- `coffeetide://` 프로토콜 등록이나 macOS 패키징은 현재 구현·배포된 기능으로 안내하지 않는다. 현재 패키징 스크립트는 Windows x64용이다.

실행·설치·패키징 명령은 [desktop/README.md](../desktop/README.md)를 따른다. 웹에 `/download/CoffeeTideBarista.zip` 링크와 로컬 파일이 존재하지만, 배포된 ZIP이 최신 소스와 같은지는 이번 점검에서 검증하지 않았다. 서명·Smart App Control 등 패키지 실행 조건도 배포 시 별도 확인한다.

## 4. 창 제어와 브리지 계약

- 브리지는 `127.0.0.1:47381`에 바인딩하고 코드 기반 연결과 Bearer 토큰을 요구한다.
- **현재 origin 허용 범위**는 설정한 origin 외에 localhost/127.0.0.1, `.vercel.app`으로 끝나는 origin, `https://coffee-tide.dongple.kr`까지 포함한다(`desktop/bridge.cjs`). ‘설정한 origin 하나만 허용’은 현재 코드와 다르다.
- `.vercel.app` 전체 허용은 특정 CoffeeTide 배포 목록으로 한정한 정책이 아니다. 신뢰 범위 축소와 origin 간 토큰 재사용 여부는 백로그 M2에서 검토한다.
- 웹은 무작위 32자리 marker를 잠시 본체 제목에 붙인다. 네이티브 도우미는 marker와 Chrome/Edge 프로세스를 확인하고 일치 창이 하나일 때만 제어한다.
- 최소화·복원 명령은 직렬 처리한다. 불확실한 최소화 실패도 복원 가능한 상태로 관리하며, 정상 연결 해제·종료에서 복원을 시도한다.
- 강제 종료·제목 변경·포커스 제한 등으로 복원이 실패하면 작업 표시줄에서 직접 복원해야 한다.
- `src/lib/ui/desktopWindowControl.ts`에는 연결 객체가 없으면 false를 반환하는 게이트가 있다. 웹 미니카드가 미연결 상태에서 `/api/util/window-control`로 우회하지 않는다.
