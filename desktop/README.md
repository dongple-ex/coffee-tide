# CoffeeTide 데스크톱 바리스타 (Windows)

투명 배경·테두리 없는 별도 창으로 캐릭터를 다른 앱 위에 표시합니다.
캐릭터를 드래그해 이동하고, 빈 배경은 아래 앱을 클릭할 수 있습니다.

## 실행

패키징된 `dist/CoffeeTideBarista-win32-x64/CoffeeTideBarista.exe`를 실행합니다.
**같은 폴더의 나머지 파일도 필요합니다.** 폴더 전체를 함께 옮겨 주세요.

소스에서 실행할 때는 프로젝트 루트에서 Node.js 22.12 이상으로:

```powershell
npm run desktop:install
npm run desktop:start
```

## 웹과 연결

1. CoffeeTide 웹을 엽니다. 기본 주소는 `http://localhost:3000`입니다.
2. 웹 설정 → AI·자동화 → 실험실에서 데스크톱 바리스타를 켜고 **데스크톱 바리스타 연결**을 누릅니다.
3. 캐릭터 말풍선에 표시된 6자리 코드를 입력합니다.
4. 브라우저가 로컬 네트워크 접근 권한을 물으면 허용합니다.

웹의 현재 바리스타 이름·색상·기본 사진·말풍선이 전달됩니다.
웹을 새로고침하거나 닫았다가 열면 다시 연결해야 합니다.
연결이 2분 이상 끊기면 말풍선과 연결 정보를 비웁니다.
자동화된 렌더링 검사의 메시지는 **샘플 데이터**이며 외부 서비스 연동 결과가 아닙니다.

## 설정과 조작

- 캐릭터 아래 **⚙ 설정** → **① 아이스커피 아이콘 / ② 현재 바리스타 사진** 선택.
- 외형 선택과 창 위치는 다음 실행에도 유지됩니다.
- 사진 캐릭터는 86px 크기입니다. 말풍선은 최대 3줄로 표시하고, 긴 내용은 마우스를 올려 확인합니다.
- 캐릭터를 드래그해 이동합니다.
- ☕ 버튼은 짧은 기본 대사를 표시합니다. ↗ 버튼은 연결된 웹 탭의 대화창으로 전환합니다. 연결이 없을 때만 웹페이지를 엽니다.
- 브라우저가 창 포커스를 제한하면 자동으로 맨 앞으로 오지 않을 수 있습니다. 기존 CoffeeTide 탭을 선택하면 대화창 전환이 반영됩니다.
- − 버튼으로 숨기고 Windows 알림 영역(트레이)을 더블클릭해 다시 표시합니다.
- **왼쪽 Shift를 빠르게 두 번 눌렀다 떼기**로 다른 앱에서도 바리스타를 표시하고 CoffeeTide 대화창 열기를 요청합니다. 각 누름은 250ms 이내, 두 번의 뗀 시점 간격은 70~500ms입니다. 오른쪽 Shift, 길게 누르기, 다른 키와의 조합은 제외합니다.
- 데스크톱 앱이 실행 중이어야 하며 트레이 메뉴의 **왼쪽 Shift 두 번 · 호출 준비됨**으로 준비 상태를 확인할 수 있습니다. 연결된 웹 탭을 재사용하고, 연결이 없을 때만 웹페이지를 엽니다. 웹만 실행 중이면 CoffeeTide 창에 포커스가 있을 때 작동합니다.
- 트레이 우클릭 메뉴에서 외형 변경, 연결 초기화, 위치 복원, 종료가 가능합니다.

## 다른 웹 주소

보조 앱을 모두 종료한 뒤, 정확한 웹 주소로 실행합니다.

```powershell
$env:COFFEETIDE_URL = 'https://your-coffeetide.example'
npm run desktop:start
```

앱은 지정한 웹 origin 하나만 허용합니다. 로컬 HTTP 또는 HTTPS 주소만 설정할 수 있습니다.
배포된 HTTPS 사이트에서의 연결은 브라우저의 로컬 네트워크 정책에도 영향을 받으므로 별도 환경 검증이 필요합니다.

## 로컬 데이터와 보안

- 통신 서버는 `127.0.0.1:47381`에만 열립니다.
- 화면의 일회용 연결 코드와 메모리에만 보관하는 토큰으로 인증합니다.
- 웹 계정 토큰, API 키, 대화 이력을 데스크톱 앱에 저장하지 않습니다.
- 저장 파일에는 외형 선택과 창 위치만 들어갑니다.
- 캐릭터 이미지는 앱에 포함된 파일만 사용합니다.
- Windows 자동 시작 등록은 수행하지 않습니다.
- 전역 단축키는 숨겨진 Windows PowerShell 프로세스에서 C# 키보드 훅을 실행합니다. 키 입력은 저장하거나 전송하지 않고, 완성된 호출 동작만 Electron에 알립니다. 앱 종료 또는 부모 프로세스 연결 종료 시 감지기도 종료합니다. Windows PowerShell/C# 실행을 제한하는 환경에서는 단축키 사용 불가 상태를 표시합니다.

## 검증 및 패키징

```powershell
npm run desktop:test
npm --prefix desktop run smoke
npm run desktop:package
```

`smoke-output/`에 두 외형의 PNG 및 검사 결과 JSON이 생성됩니다.
smoke는 별도 프로필과 임시 포트를 사용하며 실제 사용자 설정을 바꾸지 않습니다.
패키지는 서명되지 않은 로컬 개발 빌드입니다.


### 연결된 웹 미니카드의 본체 최소화 (Windows)

최신 보조 앱과 6자리 코드로 연결한 경우에만, 웹 미니카드를 열면 Chrome/Edge의 CoffeeTide 본체 창을 최소화합니다. 임시 제목 식별값과 브라우저 프로세스를 확인해 일치하는 창이 하나일 때만 제어합니다. 다른 창을 제목 일부로 추측해 최소화하지 않습니다.

왼쪽 Shift 두 번으로 본체를 복원하고 웹 미니카드를 닫습니다. 대화와 입력 중인 질문은 유지됩니다. `_` 접기는 미니카드 내용만 접습니다. 연결 해제·정상 종료 시 본체 복원을 시도합니다. 강제 프로세스 종료나 브라우저 제목 변경 등으로 자동 복원이 실패하면 작업 표시줄에서 본체를 직접 복원할 수 있습니다.

웹 코드와 보조 앱을 함께 업데이트하고 보조 앱을 재시작한 뒤 다시 연결해야 합니다. 미연결 상태, 이전 보조 앱, Windows 이외의 환경에서는 자동 최소화를 요청하지 않습니다.
